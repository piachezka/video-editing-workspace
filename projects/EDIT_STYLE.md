# House edit style — movie-style dramas / mini-movies

User note (Empty Casket EP1): for movies, add transition effects at the RELEVANT moments only,
not on every clip change. Example: fade out at the end of a clip, then fade in at the start of the next.
Keep them FAST, never slow/dragging.

Rules for every movie/drama edit instruction:
- Default between clips = hard cut.
- Use a quick fade (dip to black: ~0.2s fade out + ~0.2s fade in, 0.3–0.5s total) only at:
  scene/location changes, time jumps (night → morning, weeks later), going into / out of a flashback,
  and big emotional beats ending a sequence.
- Quick cross-dissolve (0.3–0.4s) for montage / time-passing inside the same place.
- Quick white flash (2–4 frames) only for impacts (crash, shock reveal).
- Never fade in the middle of dialogue; the fade starts after the last word.
- List the exact clip boundaries that get an effect in the instructions; everything else is a hard cut.

## Lesson (Empty Casket): montage clips with characters
Kling multi-shot clips only keep identity for the FIRST shot (the start frame). Later shots that show
locked characters drift (different faces/outfits). For montages/recaps that show characters, build the
montage in the edit from existing consistent clips under the narration audio, or generate each shot
as its own clip from its own first frame.
