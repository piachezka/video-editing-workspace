# House caption style (AI dramas / movie-style subtitles)

User feedback after Enchanting Sirens Ep 1: captions came out too thin and faint.
Use this in ALL future caption instructions:

- Plain white text, BOLD / heavy weight (thick strokes, e.g. Arial Black / Montserrat ExtraBold), noticeably larger than standard subtitles.
- Strong dark drop shadow + thick dark outline so it reads on bright AND busy backgrounds. No box/background.
- Sentence case, centered, lower-middle (65–70% down from top), above TikTok UI. Max 2 lines.
- Script = spoken lines only, no character names. Captions timed exactly to the speech.
