# House clip-prompt style (movies / AI dramas) — Kling multi-shot

User note: clips (especially for movie-style dramas) should feel cinematic by packing
2–4 shots into ONE clip with hard cuts, instead of a single static shot.

Template:
- Open with: "Three shots with two hard cuts, a slow push-in in every shot." (adjust count)
- SHOT 1 (0–2.5s): wide framing of the first frame + the action.
  HARD CUT.
- SHOT 2 (2.5–4.5s): close-up / reaction / insert of another character or detail,
  with the background described so the set stays consistent.
  HARD CUT.
- SHOT 3 (4.5–7s): close-up of the main character with a small physical action + emotion.
- Lock eyelines per shot: "eyes locked <direction> on <target> from the first frame and do not shift".
- Continuity line: faces, outfits, props and set stay exactly as in the first frame; lighting stated (e.g. bright warm light, never dark).
- Speech: "No speech." or the exact line ("says exactly once") with the voice description, and say which shot it lands in.
- Audio line: SFX listed, music yes/no, "all natural".
- Duration: ~6–8s (3 shots) or ~4–5s (2 shots).

When to use: b-roll, reactions, montage beats, dialogue clips that need coverage (wide → reaction → close-up).
Single-shot clips are still fine for tight lip-sync lines, inserts or product hero shots.
